# Instagraam 📸

شبکه اجتماعی تصویری به سبک اینستاگرام — ساخته‌شده با React، Vite، Tailwind CSS و Convex.

## امکانات

- 📝 **ثبت‌نام و ورود** با ایمیل/رمز عبور (Convex Auth)
- 🖼️ **فید** با لایک، کامنت و به‌روزرسانی Real-time
- 📷 **انتشار پست** با آپلود عکس و کپشن
- ⏳ **استوری ۲۴ ساعته** با نوار استوری و نمایشگر تمام‌صفحه
- 🔍 **جستجوی کاربران** و صفحه اکسپلور
- 🔔 **اعلان‌ها** برای لایک، کامنت و فالو
- 👤 **پروفایل** با آواتار، بیو، ویرایش اطلاعات و آمار دنبال‌کننده

## اجرا

```bash
bun install
bun run dev        # فرانت‌اند روی پورت 5173
bunx convex dev    # بک‌اند Convex
```

## ساختار

- `src/convex/` — بک‌اند Convex (اسکیمای دیتابیس، احراز هویت، پست‌ها، استوری‌ها و…)
- `src/pages/` — صفحات (لندینگ، ورود، فید، اکسپلور، جستجو، اعلان‌ها، پروفایل)
- `src/components/` — کامپوننت‌های مشترک (نوبار، کارت پست، استوری‌بار و…)

> پروژه از `VITE_CONVEX_URL` برای اتصال کلاینت به بک‌اند استفاده می‌کند؛ در محیط‌های پیش‌نمایش به‌صورت خودکار به بک‌اند لوکال روی پورت 3210 وصل می‌شود.
